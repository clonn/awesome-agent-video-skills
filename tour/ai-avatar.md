# Make an AI presenter video

You want a digital human to present a script.

## Three picks

1. **[cclank/lanshu-create-ai-presenter-video](../skills/cclank__lanshu-create-ai-presenter-video.md)** (Codex Skill, 2.0k stars, MIT): A provider-neutral skill that goes from a script and one authorized portrait to a checked presenter video.
2. **[heygen-com/skills](../skills/heygen-com__skills.md)** (Claude Skill, 458 stars, MIT): Agent skills for creating avatar videos through HeyGen's API.
3. **[Upload-Post/avatar-mix](https://github.com/Upload-Post/avatar-mix) ([catalog](../catalog/ai-avatars.md))** (Claude Skill, 130 stars, MIT): Uses your HeyGen avatar with animated HyperFrames backgrounds, music, sound effects and captions from a URL or script; the README asks for HeyGen avatar and voice IDs.

## Before you start

- Avatar services are paid third-party products; costs and consent for the portrait are yours to check.
- Use only images you are authorized to use.
- Install methods: [install guide](../docs/install.md). Choosing a base: [choosing a stack](../docs/choosing-a-stack.md).
