# Make an explainer video

You have a topic or notes and want a narrated video that teaches it.

## Three picks

1. **[Vincentwei1021/video-talkcraft](../skills/Vincentwei1021__video-talkcraft.md)** (Claude Skill, 1.3k stars, PolyForm-Noncommercial-1.0.0 NC): Builds voiceover-driven explainers with word-level sync, motion recipe cards and a camera system; its license is non-commercial.
2. **[Alisa0808/vox-director](../skills/Alisa0808__vox-director.md)** (Claude Skill, 2.1k stars, MIT): Takes a topic and produces a paper-collage explainer, covering script, keyframes, motion, voice-over, music and captions.
3. **[aijiduonadegou/Paper-Cut](../skills/aijiduonadegou__Paper-Cut.md)** (Codex Skill, 17 stars, MIT): A Codex skill for paper-cut style explainers with approval gates and quality checks along the way.

## Before you start

- Explainer tools usually call hosted image or speech models; read each README for accounts and cost.
- For math-style animation see the Manim tools in the [Explainers catalog](../catalog/explainers-and-education.md).
- Install methods: [install guide](../docs/install.md). Choosing a base: [choosing a stack](../docs/choosing-a-stack.md).
