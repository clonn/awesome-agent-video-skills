# Animate a logo or make motion graphics

You want an animated logo, titles, kinetic type or UI motion.

## Three picks

1. **[nolangz/pixel2motion](../skills/nolangz__pixel2motion.md)** (Claude Skill, 2.4k stars, MIT): Converts raster logos to SVG, then produces animated logo HTML demos, previews and motion checks.
2. **[diffusionstudio/lottie](../skills/diffusionstudio__lottie.md)** (Claude Skill, 5.5k stars, MIT): Generates Lottie animations from prompts and previews them live in a bundled player.
3. **[acelera-agency/html-animation](https://github.com/acelera-agency/html-animation) ([catalog](../catalog/motion-graphics-and-logos.md))** (Claude Skill, 6 stars, MIT): Builds animated logos and kinetic type as a single HTML file and exports MP4 in several aspect ratios (README); needs ffmpeg.

## Before you start

- Lottie output is a vector animation file rather than a finished video; check that your destination supports it.
- Install methods: [install guide](../docs/install.md). Choosing a base: [choosing a stack](../docs/choosing-a-stack.md).
