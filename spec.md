# spec.md — awesome-agent-video-skills (product contract)

Created: 2026-09-29 by PM session. Precedence: spec.md > Plans.md.

## What this is
An English-first curated GitHub repository of open-source skills, plugins, MCP servers, and toolkits that let
coding agents (Claude Code, Codex, etc.) make, edit, or animate video. It is based on zhuyansen/awesome-claude-video-skills
(credited) and adds docs, a guided tour, per-skill cards, install/usage guides, and worked examples.

## Correctness conditions
1. **Single source of truth:** `data/repos.json`. Every rendered list is generated by `scripts/build.py` (Python stdlib only).
   Running the build twice produces no diff.
2. **Coverage:** includes every repo from the upstream list or live page (target 184) plus the must-feature repos in
   `sources/handoff-facts.md`. A dead or renamed repo gets a flag, not a silent drop.
3. **Live facts:** stars, license, language, pushed_at, and archived come from the GitHub API and carry a `checked_at` timestamp.
4. **No fabrication:** each `install` / `usage` value is copied verbatim from the repo's README, with a `source_url` anchor,
   or it is `null` and renders as "See README". Descriptions are in our own words, ≤25 words.
5. **English only** in rendered files. The Chinese source text lives only in `data` (`description_zh_source`) for future i18n.
   Allowed CJK exceptions are proper nouns, which get a gloss, e.g. "CapCut/Jianying (剪映)".
6. **Attribution:** upstream safety ratings and categories are labeled as upstream's. Our own judgments (including TypeSafe
   experiments) are labeled as ours, with method and date.
7. **License notices:** each card shows the repo's license. Non-commercial licenses such as SeeCut's PolyForm NC are called out.
8. **Read-only toward listed repos:** we never install or run them. Examples are README-derived walkthroughs marked
   "not executed by us".
9. Publishing to GitHub requires explicit user approval.

## Data schema (`data/repos.json`, array of objects)
id (owner/repo), url, name, owner, category_en, category_source (upstream label), type
(Claude Skill | Codex Skill | MCP Server | Agent Tool | AI Tool), language, stars, stars_checked_at, license,
pushed_at, archived, render_base (array: Remotion | HyperFrames | Manim | ffmpeg | After Effects | Premiere Pro |
HeyGen | Blender | p5.js | Lottie | other), description_en, description_zh_source, install {command, source_url} | null,
usage {snippet, source_url} | null, safety_upstream, featured (bool), notes, judgments {} (experiment outputs, optional).
