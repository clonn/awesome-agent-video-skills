# awesome-agent-video-skills

A curated, English-first list of open-source skills, plugins, MCP servers and toolkits that let coding agents (Claude Code, Codex and others) make, edit or animate video.

Based on [zhuyansen/awesome-claude-video-skills](https://github.com/zhuyansen/awesome-claude-video-skills) (CC0) — see [Credits](#credits).

**Start here:** [Tour](tour/README.md) · [Install](docs/install.md) · [Choosing a stack](docs/choosing-a-stack.md)

**184 repositories** in 10 categories. Stars, licenses and push dates come from the GitHub API and were checked on 2026-10-10.

**How to read this list.** Install and usage text is copied from each repository's README and was **not executed by us**. If a README has none, we say "See README". Upstream's SAFE/CAUTION grade covers the README and install steps only. Always read a tool's license and install steps before running it. In the tables, `NC` after a license means non-commercial only, and `—` means the repository has no license file (default copyright applies). The "Built with" column lists rendering frameworks and services; ffmpeg is omitted because so many tools use it as a helper (cards show it under "Also uses").
