# Edit a talking-head video

You have footage of someone speaking and want it tightened, captioned or dressed up.

## Three picks

1. **[YeJe-cpu/SeeCut](../skills/YeJe-cpu__SeeCut.md)** (Claude Skill, 130 stars, PolyForm-Noncommercial-1.0.0 NC): Turns a 20-30 second talking-head clip into a motion-graphics short and checks its own result; note the non-commercial license.
2. **[louisedesadeleer/cut-video](../skills/louisedesadeleer__cut-video.md)** (Claude Skill, 104 stars, MIT): Removes silences and filler from long recordings using forced-alignment word timing while keeping laughs and comedic pauses.
3. **[Agentchengfeng/chengfeng-videocut-skills](../skills/Agentchengfeng__chengfeng-videocut-skills.md)** (Codex Skill, 3.0k stars, Apache-2.0): A Codex plugin that adds workflow skills for cutting speech, subtitles, visuals and export, backed by a separate runtime.

## Before you start

- SeeCut is non-commercial only and a 25-second sample takes about an hour (README).
- cut-video needs ffmpeg and a forced aligner that its README says it installs on first run.
- Install methods: [install guide](../docs/install.md). Choosing a base: [choosing a stack](../docs/choosing-a-stack.md).
